A single original job title for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty: **Night-Shift Reader of Terms and Conditions, Aloud** (49 characters, one line). A night-shift reader is a real-sounding job; the twist is reading terms and conditions aloud — the one thing nobody on earth ever does.

## Run it

```sh
python3 main.py
```

This writes the title to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset).
